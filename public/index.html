RobloxIA Studio

Décris ce que tu veux : l’IA écrit le code Luau pour tes scripts, animations, interfaces, maps et sons.

🔌 Plugin Roblox Studio

Le plugin ajoute un panneau dans Studio : tu y colles le code de l’IA et il crée le script, ou l’exécute pour construire une map.

  1. Clique sur le bouton : la page du plugin s’ouvre sur le Creator Store de Roblox.
  2. Clique sur Obtenir, puis ouvre Roblox Studio.
  3. Onglet Plugins → bouton IA Roblox, colle le code et choisis où l’insérer.
